Mini Exercise 2: Userlist

Type: Course Exercise · Date: 26 Sep 2026 · Role: Developer

พัฒนาเว็บไซต์ Userlist โดยใช้ HTML, CSS และ JavaScript แสดงรายชื่อผู้ใช้พร้อมรูปถ่ายและข้อมูลส่วนตัว และมีปุ่มสลับธีมสีระหว่างโหมดมืดและโหมดสว่าง

HTML CSS JavaScript Bootstrap

Reflection

What I did: สร้างหน้า Userlist ที่แสดงรูปและข้อมูลของผู้ใช้ และทำปุ่มสลับธีมมืด/สว่าง

What I learned: ได้เรียนรู้การพัฒนาเว็บด้วย HTML, CSS และ JavaScript การใช้ Bootstrap และการจัดการธีมสีระหว่างโหมดมืดและโหมดสว่าง

Challenge: ตอนแรกก็ยังไม่ค่อยเข้าใจการจัดวางรูปภาพและข้อความให้เหมาะกับหน้าจอหลายขนาด แก้ไขทำไปเรื่อยลองหลายครั้ง แล้วปรับด้วย CSS และใช้ Bootstrap

Next step: เพิ่มฟีเจอร์ค้นหาและกรองรายชื่อใน Userlist

Mini Exercise 3: Rating Component

Type: Course Exercise · Date: 29 Sep 2026 · Role: Developer

พัฒนาเว็บโดยใช้ HTML, CSS และ Bootstrap แสดงคะแนนความพึงพอใจของผู้ใช้ เป็นลำดับที่ 1 ถึง 5 และมีค่าRating เป็นแถบที่แสดงถึงคะแนนความพึงพอใจของผู้ใช้

HTML CSS Bootstrap Font Awesome

Reflection

What I did: สร้างProgress bar Rating การแสดงคะแนนความพึงพอใจ และปุ่มWrite Review

What I learned: ได้เรียนรู้การพัฒนาเว็บด้วย HTML, CSS และ Bootstrap การสร้างProgress bar Rating และปุ่ม Write Review และการใช้ไอคอนจากเว็บไซต์ Font Awesome

Challenge: ไม่ได้มีความยากมากนัก เพราะงานนี้ส่วนใหญ่ทำได้ตามที่เรียนมา

Next step: เพิ่มฟีเจอร์ให้ผู้ใช้สามารถให้คะแนนได้และเขียนรีวิวได้
