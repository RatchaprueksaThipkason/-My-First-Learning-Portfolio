What I Built

เว็บไซต์ My First Learning Portfolio ประกอบไปด้วยส่วนแนะนำตัวเอง รายละเอียดงาน ขั้นตอนการทำและReflection

การทำงานแบบ Client/Server ในงานนี้:

  • Client: Web Browser ทำการอ่านและแสดงผลไฟล์ HTML/CSS
  • Server: ตอนนี้ยังไม่ได้ใช้ Web Server จริงๆ เพราะเป็นการเปิดไฟล์จากในคอมตัวเองตรงๆ

How I Built It

  1. วางโครงสร้างเนื้อหาและแท็ก HTML และแบ่งเป็นส่วนๆด้วยsection
  2. สร้างไฟล์ style.css แยกออกมา แล้วเริ่มจัดสี ฟอนต์ และระยะห่างต่างๆ
  3. ทดสอบการแสดงผลผ่าน Web Browser

เครื่องมือและแหล่งเรียนรู้: ใช้ VS Code ในการเขียนโค้ด Youtube และ Ai ในการช่วยค้นหาตัวอย่างโค้ดตอนตกแต่ง

Reflection
